「转载 / 镜像虚假独立来源」修复与新主题自检报告

research-agent · 确定性置信引擎 · 来源身份归一落地
范围：不改动 extract_evidence 核心硬阈值计分；只改“来源身份识别”与观测。 落地口径：按决策 板①不启用轻改写近重复合并、板②未知主机默认分维持 0.5。 验证：全量回归 + eval 语料 + 新主题盲测自检。

一、背景与问题

确定性置信计分以“不同来源（URL）”为交叉验证基准。原 _url_key 只返回 url 去 #fragment：同一份正文被 N 个不同域名转载/镜像 时，会被当成 N 个“独立来源”。 在 n_total≥3 且无分歧 → high 的规则下，一堆低可信镜像站即可把单一事实刷成 high 置信——这正是“虚假独立来源”漏洞。

核心论断：真正的交叉验证应数独立编辑来源原点(origin)，而非裸 URL。 修法是在来源去重/计数这一层做 origin 折叠，完全不动计分阈值。

六、局限与后续（如实）

  • 只拦“逐字”镜像：本轮按板①不启用近重复合并，换词/截断的转载仍会按独立来源计； 若线上观测到此类刷量，可复用在 _assign_origins 预留处开启 n-gram 近重复 + 可信度门控。
  • 英文算力单位盲区：EFLOPS / TOPS / PFLOP 未入数字正则/单位表，含其的量化主张被漏抽，建议补入 _NUM_RE 与单位解析。
  • 个别量纲/复合适体：总票房/报名人数/黄金珠宝等归一与主体切分偏粗，属指标归一词典/结构切分可扩展点。
  • 主语跨桶：镜像组内不同 copy 可能被切到不同 subject 标签，但来源数已被折叠，不影响防刷。
一句话结论：来源归一方案可行、低侵入、可回退，逐字镜像刷 High 已在多主题下复验为被正确拦截； 新主题盲测所暴露的是抽取引擎的独立普适性盲区，非镜像修复引入，可另行迭代。

指标结果解读
数值召回（原文明写数值被抽出）26 / 31 = 84%单句单数值绝大多数能抽准
数值 + 口径年份双命中20 / 31 = 65%偏低多为"期望标注的年口径"差异
真正漏抽5 处集中于"一句密集多个同质数值"的复合句

5 处漏抽的共同根因（可复现、机理清晰）

同句密集多同质数值被"就近配对 + 同桶保留最近"挤掉。例如： “零售158万辆，新能源约104万辆”漏 104万辆； “环比增35%…同比增104%”漏 104%； “…下降6.8%和8%”漏 8%。 因 _sentence_claims 对“同(指标,主体,年份)只保留 dist 最近一条”， 同一句多个同类数值会互相顶掉。此前自造语料“一句只放一个核心数字”，故未暴露。

另记录的噪声/口径（如实）

  • 月份误抽：“2026年7月…销量41.9万辆”把月份 7 也抽成销量主张——真实文本含“年份+月”且当月无显式销量值时的误判。
  • 单位含噪：“1200亿元人民币”抽出为 1200亿元人（“人”并入单位）——量级词后计数名词处理过宽。
  • 口径年份差异：多数“值对但年未双命中”是标注把“同比/环比”的年份给 None、引擎给具体年，或从句年份归属不同，属口径分歧而非漏抽。
对本报告结论的修正说明：真实盲测把“自证满分”拉回真实水平——数值抽取对单值句可靠(≈84%)， 但对真实文本的高密度复合句（一段话塞多个同类数字/率值）有明显漏抽，且存在月份误抽、单位含噪。 这些都是抽取引擎的普适性短板，与镜像来源归一无关；要继续冲“成熟”，应优先补 “同句多值各落其桶”与“月份/量词歧义”，并复测真实语料逼近高召回。
