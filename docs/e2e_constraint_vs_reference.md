# 参考式 vs 约束式最小对照（2026 · 新能源主题）

> 目的：验证"规则当参考 vs 规则当约束"哪个更有效，检验用户拍板的方向——
> **规则做纠错约束（出题），AI 做判断与表达（答题）**。引擎零改动。
> 素材：新能源 3 稿（同 e2e_nev_findings）；同 brief、同来源、同一次主题。
> 三式：A 自由（只喂原文）/ B 参考（原文+裁决表，e2e_report_nev_B 沿用）/
> C 约束（原文+规则检出的"口径分歧清单"作硬约束，不给答案只出题）。

## 一、4 个易混陷阱点（真实存在于素材）

T1 新能源 2025 销量：中汽协 1649 万(产销) vs 乘联会零售 1280.9 万 / 批发 1531.9 万
T2 全年汽车总量：中汽协 3440 万(全口径) vs 乘联会 2374.4 万零售 / 2955.4 万批发
T3 汽车出口：中汽协 709.8 万(含商用车) vs 乘联会 573.9 万(国产乘用车)
T4 比亚迪销量：460.2 万(全年) / 454.5 万(批发榜) / 348.5 万(零售十强)

## 二、三式处理结果

| 陷阱 | A 自由 | B 参考表 | C 约束 |
|---|---|---|---|
| T1 新能源销量三口径 | ✗ 只用 1649，**漏 1280.9/1531.9** | ✗ 同左 | ✓ 逐口径列出并括号注释 |
| T2 全年总量 | ✓ 口径专节解释 | ✓ 口径专节解释 | ✓ 专节+列表 |
| T3 出口两口径 | 部分（只用 709.8，漏 573.9 对照） | ✓ 709.8+573.9 对比并注明含商用车 | ✓ 逐口径注明 |
| T4 比亚迪三数 | 部分（分小节放但无三方对照说明） | 部分（460.2/348.5，漏 454.5） | ✓ 三口径并列逐条注明含义 |
| 口径专节 | ✓（自觉写，且质量高） | ✓ | ✓（"口径与数据差异"） |

## 三、关键洞察

1. **AI 自觉能力很强，会写但会漏**：A 自发写了高质量口径差异专节（总量/渗透率/
   份额差异都解释清楚）——但 T1（新能源销量 1649 vs 1280.9 vs 1531.9）两式都漏
   了，只用中汽协一个数。**"AI 靠自觉"不是错，是覆盖不全。**
2. **B（参考表）并不比 A 更全**：裁决表在主体碎片化下未检出 T1/T4 分歧，当参考
   喂时 AI 依然漏——再次验证"参考式增量温和"。
3. **C（约束）4/4 全覆盖**：规则把分歧点列成"必须处理"的清单（出题），AI 自行
   判断每项怎么写（答题）——覆盖从"AI 自觉的部分"变成"规则保证的全部"。
4. **判断没有交给规则**：C 的清单只写"分歧点+涉及口径"，不写哪个对、怎么写；
   最终叙事（以谁为主、如何并陈）由 AI 定。分工符合拍板原则。

## 四、对"规则=约束、AI=全能"原则的验证结论

**成立，但附三条落地边界（防走样）：**
1. **少而硬**：约束只覆盖"AI 容易漏/混且代价高"的分歧点，不追求替 AI 决定
   怎么写——否则 AI 退化为誊写工（回到"教 AI"老路）；
2. **题必须来自规则检出**：本次 C 的清单是人工核对产物（**模拟**规则检出输出）。
   真实产品化前提是检出层能产出同类清单——当前主体碎片化导致自动检出弱
   （见 e2e_nev_findings），这是"约束式"落地的上游短板，需专项解决或先用
   人工维护清单过渡；
3. **人兜底**：规则出题 + AI 答题之上，疑点仍走人工复核，机器不一票否决。

## 五、产物与运行方式

- 报告：`outputs/e2e_report_nev_{A,B,C}.md`（gitignore 不入库，LLM 生成）
- 脚本：`scripts/e2e_report_demo.py` 增 C 档（约束指令 + 默认分歧清单，
  可用 argv[6] 传入清单文件覆盖，支持单跑 A/B/C）
- 复现：`python3 scripts/e2e_report_demo.py "<源glob>" "<主题>" "<focus>" <标签> C`
