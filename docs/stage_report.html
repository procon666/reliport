二、阶段细节与修复点

阶段1 · 簇C：底层止血（数字错拆 + 就近错配）

缺陷根因修复效果
月份/半季数字被当主张 “7月”的 7、“H1/Q2”的 1/2 被 _NUM_RE 当独立数值 token，误占 (指标,年份) 键、顶掉真量值 _numeric_tokens 剔除：后跟“月”的整数字、前导 H/S/Q 字母的标记数字（iPhone15/A100 型号不受影响） 123.6GWh 不再被 H1 的 1 挤掉

阶段2 · 簇B：句尾数值主体还原

缺陷：_subject_for 依赖“年份/量纲锚点”切主体。对“实体主体+虚词+数值”的句尾结构（无锚点）切不出，回退整句 → 不同主体的值撞同一脏主题键、被去重顶掉。

阶段4 · 收官×2：水平量定向补齐（把 97% 补到 100%）

阶段3 收口在 97%（59/61），最后 2 处漏抽均属“水平量（非比率）识别”层的定向短板，本轮逐一收口。改动聚焦“水平量该用哪个整句指标”与“量词短式是否被收录”，不触碰精确率/膨胀逻辑。

漏抽根因修复效果
219.2GWh（2026 H1 出货量） 长句句尾“市场份额/占比”走全局 _pick_indicator，劫持了句中分句“出货量”的水平量值的量纲归属 新增 _pick_level_indicator：水平量值（非 %）改用水平量整句指标；比率 % 仍走全局 _pick_indicator。取值处 cand_si = level_indicator if not is_percent else sent_indicator 219.2GWh 恢复为出货量、不再被绑成占比
8.68GW（5月单月新增装机） “1-5月累计 59.59GW”命中装机量，但“5月单月仅 8.68GW”的“装机”短式未被 _CLAIM_KEYWORDS 收录 → 命中不到量纲 _CLAIM_KEYWORDS 补“装机”（与“出货”对称的装机量短式）→ 命中并继承装机量，累计 + 单月并存 8.68GW 单月值恢复

两处均与簇A条件放开配合：恢复后与同主题既存值 _values_close 为假时正常并存，不造成单源数值膨胀（见第三节探针，0 多抽）。
