# 本地使用说明（详细版）

> 面向"自己跑一遍"的完整说明；项目概览请看仓库根目录 `README.md`。

## 一分钟上手

```bash
# 1. 配密钥（复制示例并填上你的 key）
cp .env.example .env        # 编辑填入 DEEPSEEK_API_KEY / TAVILY_API_KEY

# 2. 装依赖（建议 venv）
pip install -r requirements.txt

# 3. 启动
python3 app.py
```

浏览器打开 **http://127.0.0.1:5055**：

1. 首页输入主题（如 `2025年中国新能源汽车行业`）→ 生成（约 1-3 分钟）；
2. 报告页从上到下是：**阅读地图**（哪里可信、哪里该警惕）→ **正文**（弱证据句已降确定性；数字旁 **ⓘ** 点开看证据链：来源原句 / 可信度 / 有没有别的口径）；
3. **定制工作台**列出系统检出的"真实口径分歧"（如比亚迪 460.2 vs 454.5 vs 348.5 万辆——不同机构口径，不是谁错）。点一个你判断时会用的口径；
4. 点右上 **按我的口径重新生成**——标题 / 摘要 / 叙事主轴切到你选的数，其余口径退到差异说明。以后同一主题（及同一领域）的新报告自动套用你的偏好。

## 示例（开箱即看，已预置）

| 标识 | 报告 | 适合看什么 |
|---|---|---|
| `nev` | 2025 中国汽车市场与新能源转型 | 定制闭环最完整：比亚迪 / 新能源三口径拍板 |
| `nba` | NBA 发展历程与商业价值 | 叙事 + 数据混合、素材单源时的边界 |

## 它能做什么 / 不能做什么（重要）

**能（已验证）**：数据密集主题的多源对账（每个数字可溯源）；弱证据句自动降确定性；多机构口径分歧自动检出并给你拍板；按偏好重写报告视角并跨报告累积；出厂质量闸门（素材外数字 / "发誓句"自动拦下重写）。

**取决于素材**：拍板点数量 = 素材里"多家机构对同一指标给数"的碰撞度。碰撞多的主题（汽车 / 手机 / 新能源 / 俄乌）拍板最有用；单源综述型素材（某些行业盘点）拍板点少或为 0，此时价值退化为"看证据链 + 标记我信的来源"。

**不做**：不接 LLM 判断链路之外的叙事综述（宏大历史题材）；不替你判断对错——口径选哪个永远你说了算（勘误除外，它永远优先）。

## 成本与说明

- 生成一次报告消耗 LLM 数次调用（对齐 + 成文，可能含一次自动纠错重生成），约 1-3 分钟、费用取决于你的 DeepSeek key；
- 报告数字全部经"出厂对账"，个别"概算 / 疑不符"会如实标注供你复核，不会静默；
- 引擎确定性、无黑盒：所有规则在 `scripts/` 与 `research_agent/`，测试门禁 `scripts/ci_gate.sh`（30 项全绿）守护。

## 文件地图

```
app.py                        本地 Web 壳（首页 / 报告 / 拍板 / 偏好 / 重新生成）
scripts/theme_run.py          主题一键流水（报告 + 对账 + 示弱 + 拍板点 + 增强页）
scripts/product_pipeline.py   核心管线（检索 → 抽取 → 生成 → 出厂对账 → 示弱门禁）
scripts/decision_layer.py     拍板点自动检出（AI 对齐口径 + 规则滤噪）
scripts/strength_layer.py     证据强度账 + 示弱核查
scripts/pref_store.py         偏好库（作用域回退：话题级 > 领域级）
scripts/render_report.py      增强 HTML（阅读地图 + ⓘ 证据下钻）
scripts/ci_gate.sh            CI 门禁（30 项）
docs/                         治理 / 评审 / 产品归档文档
```

## 疑难

- **一直转圈**：查看终端日志；多半是 .env key 失效或额度不足。
- **报"素材不足"**：该主题中文资料稀疏，换个说法或加年份 / 范围再试。
- **想清空偏好**：删除 `outputs/pipes/<标识>/pref.json` 即可。
