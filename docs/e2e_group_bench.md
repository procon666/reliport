## B. schema v2 专项指标

### B1. 锚字段
- 相对值 src 251（白酒64/汽车137/手机50），anchor 有效（report/base 非空）
  **107 (43%)**；**~57% 相对值句子无句内显式年**（真实报道"同比增长"常承接前文
  年份）→ 锚失效主因是**claim 单句无年**，非解析 bug；
- 假冲突拦截（相对值 evidence 内簇 anchor 相异被拆开）：三组共 **7**（auto 5 /
  baijiu 1 / mobile 1）——"2025 出口 +21.1%"与"英国比亚迪 +485%"（不同报告期）
  等不再互判。

### B2. 实体归一
- 归一后同 (subject, indicator) 多原文形态组：**三组均为 0**。
- 结论（如实）：15 份真实同主题报道中，跨篇对**同一数值点**的复述多沿用原文措辞
  （转载/引述官方原句）→ 无需归本就同键；"异称同实体"（茅台 vs 贵州茅台）密度低。
  归并能力当前样本无法充分验证——**需更大样本或专门异称语料**（观测池记录）。
- 白酒 r05/r06/经济参考两篇同源转载被 origin 折叠 → 有效独立源减少（如实记录）。

### B3. 裁决质量（抽样 10+ 多源簇人工校验）
- **一致**多源大多合理：红旗 46 万辆 ×3 源、全国白酒产量 354.9 万千升 ×2、小米
  份额 13.1% ×2 → high 符合直觉 ✓；
- **真冲突/分歧-无主导大量是误报**（核心负面发现）：
  - auto (累计,销量): 123.58 万辆（吉利银河）vs 438.7 万辆（上汽）同桶 →
    subject='累计' 宽键异物同桶，量纲同(万辆)→误判"真冲突"；
  - auto (增长率,None): 33.09%（长城目标完成率）vs 46.9%（比亚迪）vs 6.1%
    （乘用车）subject='' → 误判真冲突；
  - baijiu (规模,2016) 1358.4万 vs 1706.86亿元 → 键失真 ✓（量纲异）；
  - **键失真判定只查量纲、漏了空/宽 subject 特异性** → 同类(量纲同但异物)误入
    "真冲突"。→ 聚合层 issue-1。

## D. 风险备注（写入交付）

1. **跨批 ingest 不自动做新旧修正比对**——修正优先仅在**同批**生效；跨批自动更新
   属新增需求（业务层全量重 ingest），不在 EvidenceStore 当前设计范围。
2. **抽取层仍封板**——subject 长尾（bench-5）走聚合层兼容/业务容忍，不开 analyzer。
3. **`verdict.kind = 分开呈现 / 分歧-无主导` 是系统正常输出非 bug**，下游 UI/消费
   需适配。
4. 真冲突数量（6）被空/宽 subject 污染，bench-2 修复后预计大幅下降——**当前数字
   不代表真实冲突率**。

## E. 结论与分支建议

- 整体链路（抽取封板 + schema v2 裁决 + EvidenceStore）**跑通且多源碰撞充分**；
  锚门拦截 7 例跨年假冲突、一致裁决符合直觉、修正 0（真实报道上修少）。
- **负面集中在聚合层 verdict 的"真冲突"精度**（issue-1，宽/空 subject）与**锚失效
  ~57%**（issue-2/4 候选）。
- 按用户分支框架：**倾向分支 B（聚合层小修）**——issue-1 修复（subject 特异性门）
  属确定性、独立 MR、可测；issue-2（季度键）与锚前文继承属更大设计，建议另评审。
- 跑分脚本/样本已存档，任何修复后可复跑对照。
