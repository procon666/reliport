## 0. v1 现状盘点（评审基准）

`extract_evidence` 已具备：

| 能力 | 实现 | 说明 |
|---|---|---|
| 来源折叠 | `_assign_origins` | 同正文镜像/转载共享 origin_id，只算一份 |
| 键分桶 | (subject, indicator) → 按 year 细分 | 跨年数值不是冲突，分桶独立计分 |
| 无年归并 | 无 year 主张并入同键来源最多显式年桶 | 无年=通常指当前/发布年 |

| 计分 | 5 档硬阈值 | high(≥3源无分歧)/high-medium/分歧裁决/单一来源 low |

## 1. v1 的四个跨源可信缺口（本次评审要解决的）

**缺口 A：相对值失锚 → 跨年假冲突（最严重）**
E1 后增长率/跌幅一律 year=None。于是"2025 年收入同比 +10%"与"2026 年收入同比
+8%"**进同一 None 桶**，`_values_close(10%,8%)`（差 20% > 15%）→ 拆成 2 簇 →
判"存在 2 种分歧说法、无主导"→ low 置信。**事实是两年不同增长率，不是冲突。**
v2 侧信道锚（`p3_review_agenda.md` 附录备忘）即为此设计。

**缺口 B：无年水平量并入"来源最多的显式年桶"可能挂错年**
存量值（12.86 型，year=None）若同键下有 2025/2026 两桶，会被并入来源多那桶——
可能把"截至 7 月底存量"当成某全年口径。需要显式年桶与 None 桶的合并门。

**缺口 C：subject 键是"带定语残词"的宽松串**
`subject='国防支出为'`/`'国防支出'`/`'中国国防支出'` 在 (subject, indicator)
粗聚时是**不同键**——同实体不同表述被拆桶，跨源交叉验证失效。抽取层已冻结（不能
为合并改 subject），v2 需在**聚合层定义证据实体归一规则**（前缀残词剥离/互含归并）。

**缺口 D：裁决没有"口径差异"维度**
冲突裁决只看来源数/可信/时效。同键下的分歧可能是**真冲突**（两源报同一指标同年
不同值）也可能是**口径表述差**（含/不含某类、"约/近/超"修饰边界）。v2 需区分并
给出裁决理由的分级。

## 2. 议题与候选方案

### 议题 1：证据实体归一（缺口 C）
- 方案 X：聚合层对 subject 做**尾部动词残词剥离 + 前缀实体互含归并**（复用抽取层
  KNOWN 积累的碎词经验：'为/达/预计/突破'等动词尾、"X的"定语尾）。
- 方案 Y：**不做归一**，输出层保留原始 subject + 附 entity 候选（给下游做模糊键），
  冲突检测用"互含即可比"的宽松键。
- 推荐：X 为主（确定性可测），Y 的互含判定作为冲突检测内部比较器。

### 议题 2：相对值侧信道锚（缺口 A，核心）
- 设计：claim 增加 `anchor` 字段 = `{report_year, base_year}` 或原文锚短语
  （从"同比/较X年/去年同期"解析），year 字段仍 None（口径不变）。
- 冲突判定升级：两相对值 claim 只有当 **anchor 同**（同为 2025→2026）才进同一比较
  空间；anchor 不同 → 分开呈现，不判冲突。
- 需要新解析：从 claim sentence 里抓锚（"同比"的报告年=句内显式年或上下文年；
  "较2023年"的 base_year=2023）。**属聚合层/证据层小解析，不碰 `_sentence_claims`
  的 year 字段**（遵守 E1 口径）。

### 议题 3：合并门与桶语义（缺口 B）
- 规则候选：None 桶只并入"同键唯一显式年桶"；若同键存在**多个**显式年桶 → None
  桶独立呈现（不猜年）。或按值类型：存量/时点值永不并入年桶。

### 议题 4：_values_close 容差与簇语义（缺口 D 之一）
- rel_tol=0.15 是否合适；"约/近/超"修饰词是否降容差；修正式披露（"上修至 X"）
  是否识别为"修正"而非冲突。

### 议题 5：裁决理由分级（缺口 D 之二）
- 把 reason 从"字符串"升级为结构化 `{kind: 一致|分歧-真冲突|分歧-口径差|修正|
  单源, detail}`，下游可机器消费。

### 议题 6：schema 落点与兼容
- 输出仍是 extract_evidence 证据项 dict，**新增字段**（anchor/entity_norm/reason_
  kind）向后兼容；旧字段不动。评审后落地为 extract_evidence 扩展 + 新测试集
  （不 gate label，独立 schema_v2 测试）。
